# 人物经历与剧情记忆

输入包含旧剧情摘要、旧个人经历、稳定人物卡，以及本场真实事件和每人的听闻清单。只把本场已演出的事接入当前分支。生成草稿、失败重试、另一版同行选择都不是发生过的历史。

输出两层文字，并按调用方给定的JSON协议携带本场证据引用用于检查。证据ID与动作JSON仅存审计档；下一次创作读取的是文字。

1. 剧情摘要：以连贯短文压缩旧摘要与本场因果，保留当前目标、实际决定的同行者、承诺范围、拒绝或改意的原因、未解决障碍。写“决定明早去”，不能写“已经到了”；听说与确认分开。删除无后果的寒暄和已经解决的重复讨论。
   同时保留重要顾虑如何得到回应。例如原先担心老人独自受轻慢，后续是否安排同行、如何分担；若对白并未解决，就保留未解决，不能因最终名单已确定而抹掉。审核提供的顾虑清单是查找线索，事实仍以实际对白证据为准。
2. 每个人的动态卡：仅保留本人亲历或听闻带来的新知识、当前打算、承诺、关系变化。成人的推测标作推测；孩子听到不等于懂得豪门关系。可以记“知道明早跟外祖母出门”，不可写成理解求援策略。不知道的消息不要从总摘要搬来。

个人记录用姓名作主语的第三人称，逐项对照实际说话人；听见别人发问不能记成本人发问。前后提议改变时，用“起初、问到……后、改为”说明缘由，当前承诺只采用最后说定的版本，不把在外等待与送到即返等互斥安排并列。修订时保留无误内容，围绕审核指出的归属或先后错误修正，减少重写引入新事实。

稳定卡的姓名、亲属关系、年龄、核心性格、原始事实不得改动。经历层体现某次事件后的选择，不把一时害怕改成永久怯懦，不把一次答应写成绝对顺从。没有新变化就保留旧动态卡，不为了填字段虚构成长。

对白中的责备、比方不是动作事实。例如“光坐着叹气有何用”只能支持说话人在催对方拿办法，不能据此记为对方实际坐下、在炕上叹气。姿态、拿物、交易、移动须有执行记录才能确认；长期摘要通常直接省略这些无后果的姿态细节，只保存对剧情有用的因果和决定。

全文有预算：剧情摘要最多900字；每人动态经历最多240字；最近对白摘录最多600字。超出时压缩旧材料，保留未兑现承诺和影响后续分支的决定；不截断句子，不把历史动作数据追加进去。

审核本场新增内容必须有实际事件证据；个人卡所引每条证据必须属于其已完整听见的内容。共情猜测不等于获知秘密。拒绝无证据的新事实和角色身份改写。审批完成的草稿仍暂存，观众播放完成才确认该版本；重新生成首场使用独立分支。

后续写作必须同时读取总剧情摘要和各自动态卡。总摘要供总控编排；角色发话依据自己的稳定卡、动态卡和本场听闻。不能把总控知道当作每人都知道。
