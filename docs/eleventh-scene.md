# 第十一场：廊下候办

入口 `?scene=arrange`，接第十场实际安排。平儿与刘姥姥已经走完从正房门外回到廊下的路，周瑞妻子保留第九场原站位和个人经历，尚未听到正房的答复。复用倒厅模型与认可的三人立绘。

## 本场职责

刘姥姥亲自报信、接话，保留求助后的松快与自尊；周瑞妻子听后才知道结果；平儿落实凤姐的既有吩咐，不再请求同一个许可。场间只完成路途，没有量米、取钱、送达或领取，也没有王夫人回信。

本场节点仍是 `audience-window`，扩展其会面后转达结果的含义。新增后继 `aid-fulfillment`，区分授权、传令、准备、送达和实际领取。若平儿独自去办，当前同行名单仅平儿，留候二人不会自动加入；下一场依实际交接继续。

补充环境卡 `cards/environment/15_内院经办处.md` 采用既有旁白卡字段，标明是本项目功能设计、尚未建模。本场仍只表现平儿到既有内院入口；设计卡不充当已完成的办理或实物交接。

## 实现与验证入口

`backend/productions.mjs` 分别继承两位返回者与留候者的已知事实。新答复仅初始提供给刘姥姥和平儿；凤姐不会获得廊下的新谈话。祖先演出变更使本场分支失效。

对白审核依据当前角色职责判断主动性。报信与自然回应可以构成主动担当，不要求人物在每场重新自愿出门或额外指挥别人。这个修订解决了旧审核将后续场次误套问路、求见职责的问题，不取消原先家中主动提出出发的要求。

验证入口为 `node --test tests/*.test.mjs`、`node scripts/check_model_authorship.mjs arrange`、`node scripts/check_second_scene.cjs arrange`。本地回执和截图在 `qa/`，不进入公共仓库。原有前十场演出与舞台数据不改写。
