# 人物底色、场次职责与开场

稳定性格、当前场景职责、已经发生的个人经历是三层资料。`data/cards/home.json` 的 personality/characterCore 描述人物底色，sceneRole 与 scene.dramaturgy 标记本场创作要求，动态经历只记录实际演出。后续场景不会把“本场主动出门”误当成所有场合都必须出头的性格模板。

## 刘姥姥

依据[原文第六回](https://zh.wikisource.org/zh-hans/紅樓夢/第006回)，她真心帮衬女儿女婿过活，能提出谋生办法，有乡间见识和人情分寸；面对豪门也会踌躇，最后能把窘迫说得让一家人笑起来。此前运行卡偏重数落、顶回与算得失，缺少亲情与自嘲，导致台词冷硬。

本轮明确的创作方向是她自己决定承担出门这件事。原文有别人劝说的细节；这里按用户要求强化主动性，并不声称完全复演原文的发言顺序。她可以不知道周瑞是否肯帮、顾虑门房难进，但不会向家人反复索取“不许埋怨”的保证。可亲来自具体回应、体谅与机敏，不靠圣人化或牺牲宣言。

## 群戏职责

- 刘姥姥：拿办法、主动承担，让一家人从烦闷中看到可试的路。
- 狗儿：带出家计压力，提供他知道的旧交信息，并承担具体分工；保留急躁和面子顾虑，不把他夸张成只会推责的人。
- 刘氏：表达母女牵挂与孩子照料的实际顾虑，参与商议，不只充当阻拦或附和的人。
- 两个孩子：提供有限、合年龄的生活反应，不承担成人决定或讲解求人道理。

内容审核新增 agency 项，必须引用刘姥姥实际主动承担的发言，并记录之前是否有人推她去。被推派之后的应承不能当作主动担当通过审核。旧版“推岳母去、成败不包”的十三句稿保存在 `tests/fixtures/granny-reluctant-dialogue.json`，供测试与内容审阅使用。当前发布验证不额外调用模型。

## 开场背景

先出现题字，再由同一总控依据初态生成简短背景文字，点明京郊狗儿家、家庭关系与秋尽冬初冬事未办。背景覆盖在定格的场景上，可略过；读完才开始人物动作与对白。它不进入角色听闻，也不预告尚未决定的同行者和求助结果。配乐可使用 prologue 时间段，正文仍避免重复总结。
