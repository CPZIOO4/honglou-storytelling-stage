# 第七场：廊下相见

入口 `?scene=reception`，承接第六场两人同行的实际决定。周瑞妻子带刘姥姥到倒厅旁院门外，首次与平儿本人相见；省略路途，不省略相见、回应与接待行动。复用第五场倒厅模型及既有三人的透明立绘。

## 角色与消息

平儿保留第五场亲耳听到的身份、来意和自己作出的安排，不重新问整套家计；第六场在周瑞妻子屋内的交谈不进入她的个人记忆。刘姥姥则已听周嫂子转告候见许可，却还没与平儿本人说过话。周瑞妻子简短引见，并依先前承诺协助必要应答。

刘姥姥有生疏感，也保留乡间生活的老练与自尊，不能只连续道谢或保证规规矩矩。平儿稳妥而有人情味，不以反复训话表现能干。本场至少落实接待或开始实际传话，不第三次商量回屋接人。原著性格依据沿用 `docs/upcoming-character-research.md`；当前回访、同行名单与应答依已经演出的分支决定。

凤姐不在场，尚无召见、回禀或资助结果。平儿若决定去向凤姐回话，当前立即行动者与原处候信者必须分开；不能把候见许可变成已准进正房。下一部分从本场真实决定接续，不预填获助结局。

## 场景与实现

`data/reception-stage.json` 复用 `assets/scene/rongfu-waiting.glb`，增加刘姥姥独立答话位和周瑞妻子陪候位。平儿的初态从第五场执行终点读取，两位来客按第六场同行安排到来。三个站位分开，交谈停步；门前终点仍属院门外，不声称已进入凤姐正房。

`backend/productions.mjs` 核对已确认的第六场及所有祖先版本，分别汇入个人经历与此前确实听到的事实。`data/reception-cards.json` 为本场环境和职责，`data/deepseek-seventh-scene.json` 为审核后的发布稿。本地生成入口 `POST /api/director/generate` 使用 `{"scene":"reception","beats":2}`。

验证入口：`node --test tests/*.test.mjs`、`node scripts/check_model_authorship.mjs reception`、`node scripts/check_second_scene.cjs reception`。前六场的发布演出与场景数据保持原样。
