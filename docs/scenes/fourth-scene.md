# 第四场 · 旧识相迎

[打开演出](https://cpzioo4.github.io/honglou-storytelling-stage/?scene=zhouhome)。当前版本 `6c2e6872-b40b-4dd1-8338-3a62132d1675`，3段、10句，人物为刘姥姥、周瑞妻子。

## 当前初态

第三场商定由孩童带路，来访者刘姥姥现在已到周瑞妻子住处门前小院。孩子只领到门前，未加入本场接待交谈，不编造他的离场对白或赏钱。周瑞妻子在屋门边，尚未与来客交谈；刘姥姥尚未获邀入屋，也未说清今日来意。屋门开着，帘子束在两侧，桌碗都是静态布景。

## 场末与知识边界

下一节点为 `audience-window`，实际到达该节点的同行者为周瑞妻子。 立即去寻平儿，请她向琏二奶奶递话，为刘姥姥求周济探路。。周瑞妻子此刻从小院出口出发去寻平儿；刘姥姥原地等候，须待平儿肯传话、周瑞妻子回来再领，才能随后过去。。计划、承诺与实际完成的行为以演出和逐人记忆区分。

- 刘姥姥家今年年成不好，过冬的衣食短缺，想求周济。
- 周瑞妻子先去寻平儿，托她向琏二奶奶递话；刘姥姥留在屋里等候。
- 若平儿肯传话，周瑞妻子再领刘姥姥过去。
- 周瑞妻子记着狗儿曾帮周瑞的情分。
- 王夫人不大管这些，府里由琏二奶奶做主；奶奶见不见、帮不帮，周瑞妻子应承不了。
