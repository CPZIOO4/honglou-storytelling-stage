# 第八场 · 正房回话

[打开演出](https://cpzioo4.github.io/honglou-storytelling-stage/?scene=report)。当前版本 `d6b4e94f-aa5e-4fd4-ae2c-91423ded5f7c`，2段、7句，人物为平儿、王熙凤。

## 当前初态

接第七场实际安排，平儿独自从内院门前来到王熙凤正房的堂屋入口，尚未开口回话。王熙凤在会客炕前空地站着，本轮第一次出现，尚不知这次来客的详情。刘姥姥和周瑞妻子仍在倒厅旁廊下候信，不在本场也听不见正房交谈。场间只完成平儿来回话的路途，不增加掀帘、端茶、翻账、来客入内、主人答复或资助。

## 场末与知识边界

下一节点为 `audience-window`，实际到达该节点的同行者为平儿。 去倒厅廊下传凤姐的话，请刘姥姥进正房见面，米粮之事当面问；周瑞妻子留在廊下等候。。凤姐吩咐后即刻动身；前提是刘姥姥仍在廊下候着，传话后只领刘姥姥进正房。。计划、承诺与实际完成的行为以演出和逐人记忆区分。

- 王熙凤决定当面见刘姥姥并问米粮之事，命平儿去请。
- 平儿答应就去请，并说明只领刘姥姥进正房，周瑞妻子在廊下陪着。
- 太太那边尚未问过，平儿不敢替凤姐做主。
- 刘姥姥是周瑞妻子领来的，狗儿祖上与太太娘家连过宗，多年不走动。
