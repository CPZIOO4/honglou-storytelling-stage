# 第十场 · 正房相见

[打开演出](https://cpzioo4.github.io/honglou-storytelling-stage/?scene=audience)。当前版本 `9102445c-c558-4468-a578-ed1207703ac5`，3段、10句，人物为刘姥姥、平儿、王熙凤。

## 当前初态

按第九场实际应允和引路，平儿已带刘姥姥走完余下路途，来到王熙凤正房堂屋。刘姥姥在来客答话空地，平儿在侍立位，凤姐仍在第八场结束的会客炕前空地。三人尚未开始当面交谈，没有礼物、茶水或钱米交接。周瑞妻子仍在廊下等刘姥姥出来，没有跟进；凤姐不知道廊下两人出来再一道走的约定。

## 场末与知识边界

下一节点为 `audience-window`，实际到达该节点的同行者为平儿、刘姥姥。 到廊下候着，等吩咐人量些米、取几串钱送出来；刘姥姥随平儿出去，预备与在廊下等着的周嫂子会合。。奶奶吩咐后即随平儿出正房；前提是到廊下候着并等量米取钱送出，米粮钱文尚未实际交付。。计划、承诺与实际完成的行为以演出和逐人记忆区分。

- 凤姐吩咐平儿带刘姥姥到廊下候着，并吩咐人量些米、取几串钱送出去；平儿应承先带人到廊下，再叫人量米取钱送出来。
- 太太跟前由凤姐自会回话；太太处此前尚未回过话。
- 刘姥姥随平儿出去，并说廊下还有周嫂子等着，正好一道。
- 米粮钱文只是吩咐待办，尚未实际交付，数目也未定。
