# 第二场 · 荣府问路

[打开演出](https://cpzioo4.github.io/honglou-storytelling-stage/?scene=gate)。当前版本 `8f903773-90a6-429f-8896-3786632de51f`，1段、8句，人物为刘姥姥、门房仆役、门房老仆。

## 当前初态

上一场最终出行安排是：清早出发，狗儿送到村口后返回，刘姥姥独自继续赶路；孩子留在家中由刘氏照看。。场间仅落实其中的出行和半程送返，其他承诺尚未兑现。承接已确定的来访人员：刘姥姥。路途省略，现在到荣府门外。没有改变同行名单。来客尚未与门役交谈，不知道周瑞今日去向或后街路线。

## 场末与知识边界

下一节点为 `backstreet-contact`，实际到达该节点的同行者为刘姥姥。 沿府墙绕到后街后门，寻太太陪房周瑞家，找周瑞媳妇替自己递话，再求太太周济些过冬米粮。。周瑞今日不在门上、其媳妇在家可递话，刘姥姥听完指路后即行动身。。计划、承诺与实际完成的行为以演出和逐人记忆区分。

- 门役只让刘姥姥靠边等，推说里头的事说不清，不肯在门上替她找人。
- 周瑞这一日往南边办事去了，不在府门上。
- 老仆指刘姥姥沿府墙绕到后街后门，问太太陪房周瑞家；周瑞媳妇在家，可替她递话。
- 周瑞是王夫人的陪房，在荣府当差。
- 刘姥姥原想托周瑞向太太递话，求些过冬米粮。
- 刘姥姥女婿家祖上与金陵王家连过宗。
