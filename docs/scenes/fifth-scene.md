# 第五场 · 廊前递话

[打开演出](https://cpzioo4.github.io/honglou-storytelling-stage/?scene=waiting)。当前版本 `2bb3523d-ffe4-4806-912c-68a8416e2067`，1段、7句，人物为周瑞妻子、平儿。

## 当前初态

周瑞妻子按第四场已确认安排，来到倒厅旁的院门外，目的是立即去寻平儿，请她向琏二奶奶递话，为刘姥姥求周济探路。。刘姥姥仍在周瑞妻子住处等候，没有跟来。平儿在院门外廊边，尚未与来人交谈，也尚不知道本次来客是谁、求什么；当前没有凤姐对这次请求的答复。

## 场末与知识边界

下一节点为 `intermediary`，实际到达该节点的同行者为周瑞妻子。 回住处领刘姥姥到倒厅廊下候着，等平儿向琏二奶奶回话。。平儿当面吩咐周瑞妻子回去领人，周瑞妻子应承后即刻动身；刘姥姥仍在屋里等候。。计划、承诺与实际完成的行为以演出和逐人记忆区分。

- 周瑞妻子回去领刘姥姥到倒厅廊下候着，并以“周嫂子带来等回话的”应对询问。
- 平儿答应得空便向琏二奶奶回明；见不见、如何周济由奶奶示下。
- 来客是狗儿家的刘姥姥，狗儿祖上与王夫人娘家连过宗，多年不走动。
- 刘姥姥家今年过冬衣食短缺，想求府里周济；先求见奶奶一面，若不得见再求递话。
- 刘姥姥眼下仍在周瑞妻子屋里，尚未到倒厅；平儿没有允诺接见或周济。
