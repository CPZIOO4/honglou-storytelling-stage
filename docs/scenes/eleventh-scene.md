# 第十一场 · 廊下候办

[打开演出](https://cpzioo4.github.io/honglou-storytelling-stage/?scene=arrange)。当前版本 `001fd944-3102-4c19-be61-e3f2999ff227`，1段、6句，人物为刘姥姥、周瑞妻子、平儿。

## 当前初态

接第十场已经应允的安排，平儿带刘姥姥从正房门外走完回廊下的路。周瑞妻子仍在第九场结束的原站位；两人回到她旁边，尚未向她说正房结果。凤姐留在正房，不在本场。只有返回路途已完成，米未量、钱未取、吩咐尚未传给经办者，没有新增丫鬟、回禀或交付。

## 场末与知识边界

下一节点为 `aid-fulfillment`，实际到达该节点的同行者为平儿。 去叫人量米取钱送出，再回来寻刘姥姥与周瑞妻子。平儿说完去去就来、周瑞妻子答应陪等后即去；前提是凤姐已吩咐量米取钱，周瑞妻子陪刘姥姥留在廊下。。计划、承诺与实际完成的行为以演出和逐人记忆区分。

- 凤姐已吩咐量些米、取几串钱送出来，平儿将去叫经办者办理。
- 平儿去叫人量米取钱，周瑞妻子陪刘姥姥在廊下稍候，送出来再寻她们。
- 周瑞妻子答应陪刘姥姥在廊下等，刘姥姥向她道劳；平儿说去去就来。
- 米钱只是吩咐待办，尚未实际交付，数目也未定。
