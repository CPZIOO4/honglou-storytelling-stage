# 第一场 · 寒家谋生

[打开演出](https://cpzioo4.github.io/honglou-storytelling-stage/?scene=home)。当前版本 `91f94e53-5089-4241-b8a2-cc14a7188536`，3段、12句，人物为刘姥姥、狗儿、刘氏、板儿、青儿。

## 当前初态

秋尽冬初，家中过冬衣食尚未置办齐。狗儿烦闷，刘氏操持家务，刘姥姥照看孩子；一家人尚未决定如何应对。

## 场末与知识边界

下一节点为 `gate-access`，实际到达该节点的同行者为刘姥姥。 去荣府寻周瑞，求他引见王夫人，讨过冬的吃食。。清早出发，狗儿送到村口后返回，刘姥姥独自继续赶路；孩子留在家中由刘氏照看。。计划、承诺与实际完成的行为以演出和逐人记忆区分。

- 刘姥姥打算去荣府先寻周瑞，求他引见王夫人，讨过冬的吃食。
- 狗儿答应清早送刘姥姥到村口，剩下的路由刘姥姥自己走；刘姥姥应下，并让家人留在家看好孩子。
- 刘姥姥答应板儿回来给他带块糕，让他在家听娘的话。
- 狗儿家与金陵王家连过宗，王夫人如今在荣府；刘姥姥早年带闺女去过王家。
- 周瑞跟狗儿爹办过事，是王夫人的陪房；狗儿认为他若肯帮，话能递到王夫人跟前。
- 周瑞多年没来往，不知还认不认这门旧；门房未必肯替穷亲戚通传；刘姥姥路不熟。
