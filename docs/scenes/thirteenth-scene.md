# 第十三场 · 携米归家

[打开演出](https://cpzioo4.github.io/honglou-storytelling-stage/?scene=homecoming)。当前版本 `2f556cc3-6921-4c8f-9e1c-3fa10a75f85d`，3段、9句，人物为刘姥姥、狗儿、刘氏、板儿、青儿。

## 当前初态

按第十二场已说定的送行与返家安排，省略周瑞妻子送到后门、在后门分手、刘姥姥自行走回村里的路程。刘姥姥已进狗儿家屋门内，米袋和钱袋仍由她持有，尚未交给家人；途中未购物或花钱。狗儿先前送到村口后便返家，现与刘氏、板儿、青儿在屋里，尚未问答。家里人只看见她和带回的东西，不知道荣府经历。周瑞妻子和平儿没有跟来，也不知本场谈话。

## 场末与知识边界

本场原地收束，没有新的同行安排。 在家说明带回米钱的来由，安顿眼前家用，并如实回应板儿的糕。。已在家谈妥眼前安排，不再出门。。计划、承诺与实际完成的行为以演出和逐人记忆区分。

- 刘氏安排把带回的米先搁灶边、钱由狗儿收着，明儿先买柴；狗儿应承照办。
- 刘氏说这些先顶一阵，未说足够过一冬。
- 板儿问起糕，刘姥姥说这回没顾上买，答应缓一缓再补。
- 米钱来由已向家人说明为府里掌家的琏二奶奶吩咐给的，家中据此安排眼前用度。
