# 第三场：后街寻人

入口为 `?scene=backstreet`，第二场结尾可点击继续。本场承接已确认的角门问路结果：刘姥姥独自沿墙绕到后街，已经知道应找“太太陪房周瑞家”，不重新询问周瑞是谁，也不恢复板儿同行。

后街 GLB 与引路孩童的正背面、六种头部表情沿用桌面已确认素材。摊担、后门和门内砖地是既有模型；商品种类、尺寸和具体左右方位属于舞台布局，不宣称是原著逐项复原。第三场实际走位止于后门外入口，尚未进入周瑞妻子住处。未配置小贩与其他儿童，不给场外人物台词或假造回应。

孩童的作用是凭邻里生活经验认住处、回应带路请求。称呼含混才追问；已经说明太太陪房周瑞家时可以直接回答。这个角色是无名孩子的舞台代表，没有补造姓名、亲缘、成年人的求援策略或府内权力知识。其文字音效单独配置。

## 状态与动作

`backend/productions.mjs` 读取第二场已确认的文字摘要和每人的经历，生成本场运行卡。首场的“未定出行办法”和“谁同行尚待商议”不会继续作为当前事实注入；稳定身份与已听见的消息分别保留。新出现的孩子不继承家中或角门的对话。

舞台编排支持 `afterMoves`：本段最后一句显示完后，才执行收尾移动。孩子可先行，刘姥姥延后0.8秒跟上；不是口头还没答应就已经带路。移动时不继续播放该段对白，编译器仍检查实际路线、时段、听闻与障碍物。

记忆审核输入包含已执行移动及最终所在位置的文字说明，用来区分“到后门入口”与“已进屋见人”。这些执行资料保留作审核依据，后续创作仍读取限额内的剧情摘要和个人经历。

第三场的直属来源是第二场，第二场又来源于第一场。更换任一祖先版本都会使旧第三场失效，不能把旧分支静默接到新第一场后面。记忆在同一故事分支内递增到 revision 3，离场家人与门役的个人经历保持原样。
