# 第六场：回屋传信

入口 `?scene=returnhome`，接第五场《廊前递话》。这是实际分支产生的回访：周瑞妻子先独自找平儿，听到候见安排后回屋接刘姥姥。只省略返回的路途，通知与是否同行由本场真实交谈完成。

## 场次与角色

复用第四场住处模型和已认可的刘姥姥、周瑞妻子立绘。刘姥姥的位置从当前第四场执行终点读取，个人经历从第五场保留的个人记忆读取；不把她重置到初次来访的门外。周瑞妻子回到门边，可先进自己的屋里说话。双方商量好之后才能离开；路径经过屋门，不穿墙，结束仍在住处出口。

刘姥姥此前已主动求助，本场接住消息、表达感激或具体顾虑、决定是否跟去即可。周瑞妻子熟悉府中事务，转告实际许可范围；不重复问家境，不用训诫表现能干。场次审核区分“回来邀请同行”和“家中先推派她出门”。

平儿的原话与新安排仅进入周瑞妻子的初始知识；刘姥姥须听本场转述。平儿、凤姐均不在场，不凭空生成场外回禀和召见。能在廊下候见不等于已经准见或得到资助。这个回访是项目第五场决定产生的演绎，不宣称是原著中的固定场次。

## 接入与验证

- `backend/productions.mjs` 从第五场实际交接和第四场等候记录建立当前初态；前序版本改变会使第六场失效。
