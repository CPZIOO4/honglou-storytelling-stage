## name

狗儿家

## description
```
[身份]
京郊农家住处，屋内与小院相接，家人可自由走动。

[空间]
一间生活起居屋连小院。炕、灶和桌凳靠墙，中间留出交谈与走向院门的地方。

[材质]
土地面、土墙、旧木桌凳、粗布被褥。

[光]
窗纸透进散光，院门带来较亮的一条光；夜里若点灯，只照到近处。

[声]
风擦窗纸、碗放在木桌上的轻响

[气味]
灶灰、旧柴

[体感]
门边通风，炕边相对暖；具体天气随场次变化。

[走位锚点]
A1 炕前——能看见屋中家人，靠炕的人并不自动拥有决定权。
A2 桌旁——放茶碗、听人说话，桌凳占地不能穿过。
A3 屋中——家人商量事情的空处，正常说话同屋可闻。
A4 低声交谈处——屋中相邻的两个独立站位；两人靠近后才能低声说。
A5 门内——可与屋里答话，也可看见小院。
A6 小院——屋里只见门口这一带，低声话不传入屋。
```

## personality
```
屋小容易听见，家人却不一定愿意把难处说透。
桌凳能留住人坐下，门又提醒人还有外面可去。
家人彼此熟悉，商量办法时仍需等别人把话说完。
```
