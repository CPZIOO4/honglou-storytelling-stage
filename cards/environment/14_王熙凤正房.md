## description
```
[身份]
王熙凤住处的堂屋与相连房间，既待客也处理家事。

[空间]
堂屋连接候见东间与会客处，门帘和房间转折使视线、听觉不完全相通。

[材质]
砖地、木炕沿、漆木器、织物门帘与坐褥。

[光]
窗光落在炕沿，帘后较暗；器物只在入镜或被使用时点明。

[声]
自鸣钟机声、茶盘与碗盏、帘外脚步

[气味]
茶水、手炉炭火

[体感]
屋内较暖，开帘时会带入冷气。

[走位锚点]
A1 正房门外——候传或通报，不能默认听清所有内室话。
A2 堂屋——连接两边房间，脚步可被邻近人听到。
A3 东间候客位——可等候或用饭，桌子须存在才可使用。
A4 会客炕前——来客与主事者答话，身份不自动决定每句回应。
A5 主事者位置——王熙凤处理来访与家事，未在场时保持空位。
A6 侍立与递茶位——平儿等候、递茶和进退的位置。
A7 帘边低语处——两名角色靠近后可私下交代，仍按声区和距离判定听众。
```
