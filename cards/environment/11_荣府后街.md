## description
```
[身份]
荣府后门外的小街与门内的一小段仆役巷道。

[空间]
墙边摆摊担，中间留人走动；后门把街面与内巷分开。

[材质]
磨旧砖石、墙灰、木摊架、竹编筐和粗布遮棚。

[光]
街面受天光，摊棚下较暗，门内的墙面反射少量散光。

[声]
摊担器物轻响、孩子脚步与交谈、街上来往声

[气味]
蒸面食、炉火

[体感]
街口有风，棚下略能避风。

[走位锚点]
A1 街口——从角门方向绕来，能看见后门及摊担。
A2 食物摊前——可看商品；摊担与炉子是固定障碍。
A3 玩具摊前——能看见摊上物件，不自动触发购买。
A4 孩子活动处——与摊位留开距离，街边的人可看见。
A5 后门外——询问或等待；门开时可看见内巷。
A6 后门内巷——通向住处，转角后看不见大部分街面。
```

## personality
```
人多容易找到人，也容易把称呼叫混。
门敞着像是随时能进，进去后仍需知道要找谁。
摊上的物件吸引孩子，带路却需要把目光从物件上移开。
```
