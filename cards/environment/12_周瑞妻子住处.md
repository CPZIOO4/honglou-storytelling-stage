## description
```
[身份]
荣府仆役居住区域的一处小院与起居屋；屋主是周瑞妻子。

[空间]
门外一小块等候处，入门可到屋内坐谈，再由院门返回巷道。具体尺寸留给模型绑定。

[材质]
砖地、灰墙、木桌椅、素布门帘。

[光]
院中天光较亮，屋内光从门与窗进入，门帘落下后明暗分开。

[声]
院门开合、斟茶、巷道远处脚步

[气味]
茶水、炭灰

[体感]
院内通风，屋内可避冷。

[走位锚点]
A1 院门外——来客可呼唤，屋内不自动听清低语。
A2 院门内——主人迎客或送客的位置。
A3 屋门边——可以通报，不能挡住出入。
A4 桌前客位——主人示意后可以落座；不强制出现坐姿。
A5 主人侧位——与客位能相对交谈。
A6 屋内低语处——两个独立近距站位，远处的人只能看到靠近动作。
```
