## description
```
[身份]
通往王熙凤住处的候见与通报空间，包含倒厅、影壁旁及院门外。

[空间]
等候处与内院之间有转折，影壁遮住部分视线。外面的人不能直接看到内室。

[材质]
青砖地、灰墙影壁、木门框、素色帘。

[光]
院中天光与倒厅阴影相邻，转过影壁才看到另一片亮处。

[声]
往来脚步、门帘轻响、隔院不清楚的说话声

[气味]
木器、少量炭火

[体感]
廊下避风，院中较凉。

[走位锚点]
A1 倒厅外——来客到达，能看见等候处。
A2 等候位——停留等消息，不能据远处动静编造内室谈话。
A3 影壁旁——转折处，视线被墙遮挡。
A4 院门外——通报返回时会经过，可向来客交代答复。
A5 院内廊下——获准后进入，仍不是正房内室。
A6 回话近位——两个人相邻站立，低语只向近旁听众开放。
```

## personality
```
离主事的人已经很近，能知道的消息却仍然有限。
等候使人停住，通报的人不断进出。
礼数让出入有序，也可能让一句询问迟迟到不了对方耳边。
```
